# 调弦 · Guitar Tuner

基于手机/电脑麦克风的免费在线吉他调音器，单文件 HTML，无需安装、无广告。

## 功能

- **麦克风实时测频**：自相关算法检测基频，六根弦检测误差 ±1 音分以内
- **自动识别琴弦**：拨弦后自动判断当前调的是哪根弦，也可手动锁定
- **音分表盘**：黄铜指针 + ±50 音分量程，±3¢ 内绿区提示"准了"
- **调弦指引**：实时提示"偏低 · 拧紧琴钮" / "偏高 · 放松琴钮"
- **数据读数**：实时频率、音分偏差、输入电平

## 标准定弦（EADGBE）

| 弦 | 音名 | 频率 |
|----|------|-------|
| 6 | E2 | 82.41 Hz |
| 5 | A2 | 110.00 Hz |
| 4 | D3 | 146.83 Hz |
| 3 | G3 | 196.00 Hz |
| 2 | B3 | 246.94 Hz |
| 1 | E4 | 329.63 Hz |

## 使用

1. 打开页面，点击"开启麦克风"并授权
2. 拨响琴弦，手机与吉他保持 30–50 cm
3. 按指针提示拧紧/放松琴钮，直到指针落在绿区

> 注意：麦克风功能需要通过 http/https 访问，直接双击本地文件部分浏览器会禁用麦克风。建议在安静环境中使用。

## 技术栈

- Web Audio API + 自相关（autocorrelation）基频检测
- 纯 HTML/CSS/JS 单文件，无依赖、无后端
