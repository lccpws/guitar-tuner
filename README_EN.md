# Tune · Guitar Tuner

[中文](README.md)

A free online guitar tuner built on your phone or computer's microphone. Single-file HTML — no installation, no ads. Supports both Chinese and English (auto-detects your system language, with a manual switch).

## Features

- **Real-time pitch detection via microphone** — autocorrelation algorithm, all six strings accurate to within ±1 cent
- **Automatic string detection** — identifies which string you plucked (confirmed over 4 consecutive frames to avoid jitter); manual lock also available
- **Cent dial** — brass pointer with a ±50 cent range, green zone indicates "in tune" within ±3¢
- **Snap lock** — locks as "in tune" at ±3¢ and only unlocks beyond ±6¢, so the reading stays steady without flicker
- **Stable anti-interference** — automatic octave-error correction, single-frame outlier rejection, and median filtering keep readings steady in noisy environments
- **Tuning guidance** — live hints of "too flat · tighten" / "too sharp · loosen"
- **Live readings** — smoothed frequency, cent deviation, and input level
- **Signal hold** — keeps the reading through brief silences between plucks instead of resetting

## Standard Tuning (EADGBE)

## Usage

1. Open the page, click "Enable Microphone" and grant permission
2. Pluck a string, keeping the phone 30–50 cm from the guitar
3. Follow the pointer, tightening or loosening the peg until it lands in the green zone

> Note: microphone access requires an http/https connection — opening the file directly by double-clicking disables the microphone in some browsers. Best used in a quiet environment.

## Tech Stack

- Web Audio API + autocorrelation pitch detection
- Octave correction + outlier rejection + median filtering to suppress octave errors and noise jumps
- Adaptive pointer smoothing: fast tracking on large deviations, fine convergence near the target
- "In tune" decision with hysteresis (±3¢ lock / ±6¢ unlock)
- Pure HTML/CSS/JS in a single file, no dependencies, no backend

## Android App

The `android-app/` directory packages this tuner into an offline Android app using [Capacitor 6](https://capacitorjs.com/) — no internet or browser needed, install the APK directly.

**Features**
- All page assets and fonts embedded; fully offline
- Microphone permission and startup theme adapted for the HarmonyOS 4.2 compatibility layer
- Spherical-stripe logo launcher icon, one step from welcome screen to tuning

**Local build** (requires Node.js, JDK 17, Android SDK platform 34)

```bash
cd android-app
npm install
npx cap sync android
cd android && ./gradlew assembleDebug
```

The output is at `android/app/build/outputs/apk/debug/app-debug.apk`.

Directory notes:
- `www/` — web source (the merged single-file `index.html` welcome + tuner screens, logo, fonts); this is the source you actually edit
- `android/` — Android project generated by Capacitor
- `design/` — logo design drafts and icon generation scripts (history)
- `capacitor-cordova-android-plugins/`, `android/app/src/main/assets/public/`, etc. are generated by `cap sync` and not version-controlled
